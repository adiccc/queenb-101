# QueenB 101 — האתר של הקבוצה

אפליקציית Web מקומית בעברית לפעילות שנתית עם חניכות חטיבת ביניים. היא כוללת מסע קבוצתי, חידון, לוח מטרות, סקוואד דמויות, יצירת אווטארים בעזרת Cloudflare Workers AI ואתגרי קוד קצרים למפגש הראשון.

עמוד **הקמע שלנו** מוסיף פעילות קבוצתית בת שבע החלטות שבסופה נוצר קמע אחד מכל הבחירות. השאלות נמצאות ב־`lib/mascot/questions.ts`, ההקשר וה־prompt של QueenB ב־`lib/mascot/prompt.ts`, והחיבור ליצירת התמונה ב־`app/api/mascot/route.ts`.

## הפעלה ראשונה

דרישות: Node.js 22 ומעלה וחיבור לאינטרנט בזמן התקנת החבילות ובזמן יצירת אווטאר.

```bash
npm install
cp .env.example .env.local
```

החיבור המוגדר כברירת מחדל משתמש ב־Worker הפעיל של QueenB. אפשר להעתיק את `.env.example` אל `.env.local` כדי להחליף בעתיד את כתובת ה־endpoint.

להפעלת האתר ולפתיחתו בדפדפן בפקודה אחת:

```bash
npm run queenb
```

אפשר גם להריץ `npm run dev` ולפתוח ידנית את `http://localhost:3000`.

## פרטיות ואחסון

- טקסטים והגדרות נשמרים רק ב־`localStorage` של הדפדפן המקומי.
- האווטארים נשמרים רק ב־IndexedDB בדפדפן המקומי.
- האווטאר נוצר מתמונת פנים ומפרומפט דרך Cloudflare Workers AI. התמונה מוקטנת בדפדפן, נשלחת רק ליצירה ואינה נשמרת בשרת המקומי או באפליקציה.
- אין analytics, tracking, authentication או מסד נתונים בענן.
- מחיקת דמות ומצב המדריכה מאפשרים למחוק נתונים בקלות.

## מצב מדריכה

לחצו על הכתר בפינה העליונה, או השתמשו בקיצור `Cmd/Ctrl + Shift + T`.

במצב מדריכה אפשר לערוך ולמחוק תוכן, להציג את כפתורי "פתחי את הקוד", לייצא ולייבא גיבוי מלא (כולל תמונות), ולאפס את האתר. כל שינוי תקין באתגר קוד נשמר מיד. קוד לא תקין מציג הודעה ולא משנה את האתר.

## גיבוי

`ייצוא גיבוי` מוריד קובץ JSON הכולל את תוכן הקבוצה ואת האווטארים המקודדים. `ייבוא גיבוי` משחזר את שניהם באותו דפדפן או במחשב אחר.

## חיבור ה־AI

ה־client פונה ל־`/api/avatar` ול־`/api/mascot`. שני ה־routes משתמשים ב־`lib/ai` וב־`AvatarProvider`, שפונה ל־Cloudflare Worker עם המודל `@cf/black-forest-labs/flux-2-klein-4b`. האווטאר נשלח כ־`multipart/form-data` עם `prompt` ו־`input_image_0`; הקמע נשלח באותו פורמט ללא תמונת reference. כתובת ברירת המחדל נמצאת ב־`lib/ai/cloudflare-provider.ts`, וניתן לדרוס אותה בעזרת `CLOUDFLARE_IMAGE_ENDPOINT`.
